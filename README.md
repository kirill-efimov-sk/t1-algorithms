## Предварительные требования

Для работы с проектом у вас должны быть установлены:

- [Node.js](https://nodejs.org) (рекомендуется LTS версия)
- npm (идет в комплекте с Node.js)

## Установка и запуск

1.  **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/kirill-efimov-sk/t1-algorithms.git
    cd <имя-папки-проекта>
    ```

2.  **Установите зависимости:**

    ```bash
    npm i
    # или, если используете yarn
    yarn i
    ```

## Скрипты (package.json)

- `npm test`: Запуск тестов (тесты имеют расширение .test.ts)
